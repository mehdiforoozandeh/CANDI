CANDI · weekly update · dual metadata-conditioning (crux q15)

The model learns to read metadata — but not to act on it.

A controlled test of whether CANDI can be steered by separate input & output metadata — the precondition for metadata-controlled denoising / "supertracks".

What we built

A synthetic testbed on real count data: apply a known transform to the input and an independent one to the output, hand the model the transform “type” as metadata, and measure input-understanding, output-steering, and reconstruction separately.

Result

✓Encoder — input understanding works. It factors out the input transform (latent stays invariant yet discriminative).
✗Decoder — output steering does not. Output barely responds to the output metadata, even as reconstruction improves.

Why it matters

The model reconstructs from the input shortcut and ignores the output metadata — the same “metadata pathway collapse” we see in real CANDI, now isolated under full control. Three confounds ruled out first (decoder pooling, count-tail divergence, conditioning init) — so it’s a real result, not a bug (21/21 correctness gates pass).

Open / next

Decisive control (queued): make the input uninformative so the output metadata is the only route to the target. If steering then appears → “learnable, but suppressed by the shortcut.” Implication for CANDI: to get depth-control / supertracks, training must require the metadata (masking / imputation), not just provide it. Then the full sweep: compositional generalization + easy-vs-hard transforms (already staged).
