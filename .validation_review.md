## Code Structure Validation

### Data Loading (`_load_validation_data`)
✅ **Correct**: 
- Loads T_* biosample for input (X, mX, avX)
- Loads T_* ground truth (Y_T, P_T, Peak_T) for upsampled assays
- Loads V_* ground truth (Y_V, P_V, Peak_V) for imputed assays
- Properly handles control data
- Reshapes data to context windows correctly

⚠️ **Note**: P_merged and Peak_merged are created but only used for alignment (min_rows calculation), never passed to model. This is correct - model only uses count data as input.

### Prediction (`_predict`)
✅ **Correct**:
- Proper batch processing
- Mixed precision (torch.amp.autocast)
- Correct masking of sentinel tokens
- Returns 6 outputs: n, p, mu, var, df, peak

⚠️ **Intentional Design Decision**: 
- Uses `model.train()` instead of `model.eval()` with comment "Use batch statistics (avoids corrupted running stats in BatchNorm)"
- This is intentional to avoid issues with running statistics during validation
- **Recommendation**: Consider using `model.eval()` with `torch.no_grad()` if batch statistics are stable

### Loss Computation
✅ **Correct**:
- `_compute_count_nll`: Properly filters invalid values, computes NB NLL
- `_compute_signal_nll`: Handles multiple distribution types (Gaussian, Laplace, Student's t, Gamma, MSE, MAE)
- `_compute_peak_bce`: Clamps predictions to avoid log(0)
- All return `float` values (not tensors)

### Metrics Computation (`_compute_assay_metrics`)
✅ **Correct**:
- Computes pearson, spearman, MAE, MAE-R2 for counts and p-values
- Computes AUCROC for peaks
- Includes GW (genome-wide), gene, prom (promoter), and 1obs (1-observation) metrics
- Uses `safe_metric` wrapper to handle exceptions and NaN values

### Aggregation Logic (`run_validation`)
✅ **Correct**:
- Properly separates upsampled (ups) vs imputed (imp) assays
- Upsampled: assays in T_* (compare predictions against T_* ground truth)
- Imputed: assays in V_* but not in T_* (compare against V_* ground truth)
- Computes per-assay metrics, then aggregates using median
- Proper namespacing: `val_loss/*`, `val_metrics/*`, `val_loss_per_assay/*`, `val_metrics_per_assay/*`
- ✅ Now includes perplexity metrics in loss aggregation

## Logical Flow Validation

1. ✅ For each V_biosample:
   - Load corresponding T_biosample data
   - Load V_biosample ground truth
   - Run model prediction using T_biosample as input
   - Compare predictions to T_* ground truth for upsampled assays
   - Compare predictions to V_* ground truth for imputed assays

2. ✅ Compute per-biosample, per-assay metrics
3. ✅ Aggregate across biosamples using median
