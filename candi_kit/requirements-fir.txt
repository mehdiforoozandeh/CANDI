# Exact rebuild on Fir (Alliance Canada) — the CVMFS-wheelhouse half of the environment.
#
# EVERY line in this file resolves under `pip install --no-index`. Packages that are NOT in the
# wheelhouse live in requirements-pypi.txt and are installed in a second, separate command — pip
# resolves a requirements file atomically, so one unresolvable line installs NOTHING.
#
# Full recipe, copy-paste:
#
#   module load python/3.10.13
#   virtualenv --no-download myvenv && source myvenv/bin/activate
#   pip install --no-index -r requirements-fir.txt     # CVMFS wheelhouse
#   pip install -r requirements-pypi.txt               # PyPI; needs internet (login nodes have it)
#   pip install --no-deps /path/to/candi_kit           # the kit itself
#
# Use `--no-deps` and a NON-editable install: `pip install -e` writes an .egg-info into the source
# tree, which fails on a shared read-only copy of the kit. See README §4.1.
#
# No cuda/cudnn module is needed: the +computecanada torch wheel bundles its own CUDA runtime.
